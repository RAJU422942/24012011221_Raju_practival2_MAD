# MADPractical_2 - Android Activity Lifecycle

A simple Android application developed as part of Mobile Application Development (MAD) Practical. This project demonstrates the Android Activity Lifecycle and basic UI layout using ConstraintLayout.

## Features
- **Activity Lifecycle Tracking**: Implements all major lifecycle methods:
  - `onCreate()`
  - `onStart()`
  - `onResume()`
  - `onPause()`
  - `onStop()`
  - `onRestart()`
  - `onDestroy()`
- **User Notifications**: Displays `Toast` messages and `Logcat` entries whenever a lifecycle state changes.
- **Custom UI**: 
  - Purple header bar with the application name.
  - Vibrant yellow background.
  - Centered "Hello World!" text with bold and italic styling.

## Screenshots
The application displays a message (Toast) like "onResume function called." whenever the activity enters the resumed state.

## Technical Details
- **Minimum SDK**: 24
- **Target/Compile SDK**: 37
- **Language**: Kotlin
- **UI Layout**: XML (ConstraintLayout)

## How to Run
1. Clone the repository or download the project.
2. Open the project in **Android Studio**.
3. Sync the project with Gradle files.
4. Run the app on an emulator or a physical Android device.
5. Observe the Toasts on the screen and the Logs in the `Logcat` window (filter by tag: `MainActivity`).
